LAUDO WEB v16.2_WEB — PILOTO

Arquivo principal: index.html

Publicação:
1. Publique o conteúdo desta pasta em um servidor/site estático.
2. O endereço deve abrir index.html.
3. Não é necessário banco de dados para este piloto.
4. O preenchimento, salvamento do trabalho, leitura de planilhas e montagem dos PDFs ocorrem no navegador do usuário.
5. Esta versão mantém as bibliotecas PDF-Lib e SheetJS carregadas por CDN, exatamente como a v16.2 aprovada.
6. Antes de uso com documentos reais/confidenciais, submeta a solução à avaliação interna de segurança/TI.
7. Para uma versão corporativa sem dependência de CDN, as bibliotecas deverão ser hospedadas junto da aplicação após a validação/licenciamento interno.

Teste após publicar:
- preencher e validar guias;
- salvar e reabrir avaliação;
- importar XLSX/CSV;
- anexar PDFs no item 9;
- gerar Laudo + Anexo I + anexos em um PDF consolidado.
